# Getting Started

Welcome to the platform. To begin:

1. Create an organization and invite teammates.
2. Generate an API key from the dashboard.
3. Set usage limits and alerts to avoid unexpected spend.

## Common onboarding issues

- **Permission denied while creating keys**: ensure the user has `org_admin` role.
- **Webhook test fails**: verify your endpoint returns HTTP 2xx within 10 seconds.
- **Latency in first calls**: first requests may be slower due to warmup.
